# hx-api-diff-cli

Tracks **API attack surface drift** between OpenAPI 3 releases: removed routes
(breaking), newly exposed admin paths (additive), and security scheme changes.

```bash
hx-api-diff diff openapi-v1.yaml openapi-v2.yaml
```
